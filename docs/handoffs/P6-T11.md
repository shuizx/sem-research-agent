## Architecture and functional evidence

The default `cli.agent.run` composes a live strict supervisor policy or an explicit offline policy.
The supervisor is a real `StateGraph`: decide, delegate one worker, observe its validated terminal
result, then decide again. It allows only Research and Code and at most three delegations.
The worker receives a bounded goal and validated target; its result includes terminal status,
compact summary/reason, selected paper identity when available, public code URLs and relative
artifact references. Full reports and worker transcripts are not sent back to the supervisor.

Research and Code wrap the existing graphs. `inherit_checkpointer=True` compiles those child graphs
without an independent saver; the old default remains unchanged. `GraphInterrupt` is explicitly
re-raised through the supervisor. The CLI presents only top-level interrupts and submits human
`Command(resume=...)` decisions. Worker dependencies/graphs are retained during that request.
Completed child retrieval is restored from the parent checkpoint rather than replayed on ordinary
resume. No approval fields exist in a supervisor proposal.

The actual fixture CLI compound test produced Research `success`, selected
`paper-arxiv-2608.01234`, followed by Code `success` for the returned
`https://github.com/example/sem-classifier` at commit `bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb`.
Candidate rejection stopped after one delegation. The default CLI repository-reject regression
continued to use the original human prompt, cancellation message and status identity.

Fresh worker status, not current-context fields or printed output, determines success. Failure,
rejection or no-results terminates delegation; stale code links cannot supply a new paper result.
Code targets must occur in explicit input or validated successful evidence. Model/provider/schema
errors and model/delegation limits produce safe explicit failure codes. Live function-calling
output is Pydantic validated; text containing JSON is not parsed as a substitute.
